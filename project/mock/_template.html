What the art is doing

The god is the hero, not the list. The portrait breaks its own bezel, the ring turns slowly, the element sits on the rim. You know whose Exit this is before you read a word.

Rank without a number

I, II, III in the corner and one card lit gold. No score, no percentage, no bar. The sentence carries the reasoning, which is the rule the rating engine already lives by.

The fourth card

The reject verdict gets its own colour and its own frame, because it is not a fourth option. It is a different kind of answer. No other tool prints this.

Tap it

Selecting a card dims the rest. That is the whole interaction. Nothing expands, nothing navigates.

Dead

Dead is the feature

It gets the banner, the crack, and the only animation on the screen that draws the eye upward. Everything else is still. Silence is the normal state, so movement means something ended.

The state is the colour

Four pills on a positional ramp. A player reads the shape of the list before reading any row, which is the whole four-second requirement.

No table

Rows, not columns. Art on every one. The moment this becomes a grid with sortable headers it stops looking like the game and starts looking like a wiki.

Struck through, not removed

A dead target stays on screen, greyed and struck. Hiding it hides the lesson, and the lesson is the reason anyone tells a friend about this.

Underneath

The Kit

What Claude Code would need to build any other screen and have it match.

Surface ramp

--surf-0 to --surf-3. Positional, so darkest is always 0 and a class means the same thing if the theme is ever flipped.

The metal

Bronze through to lit gold. Frames, rules, chips and the recommended card. Nothing else is allowed to be gold.

Verdict ramp

--verdict-0 is gone, --verdict-3 is on track. Named by position, never by colour, so nothing in the code says "red".

Moonlight

Enodia's own light. Glows, motes, the crossroads mark. Never used for state, so it never competes with a verdict.

Type

Storm Ring

Cinzel, letterspaced caps. Names, headings, ranks and pills only.

The last piece of a duo still on the table.

Spectral, light weight. Every sentence the tool says out loud. Both are lookalikes. The game's own fonts do not ship.

Motion

  • Ambient drifting motes, breathing glow, slow region pan. Never stops, never asks for attention
  • Emphasis a single shimmer sweep on the recommended card, 4.6s
  • Event the snuff and the crack, only on a death. The only motion that pulls the eye
  • Response lift on press, dim the rest. 320ms, one curve everywhere
